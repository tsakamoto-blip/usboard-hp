カラー写真 + 背景白

代表メッセージのセクションの背景をダークからサイト全体と同じ明るい背景色に変更し、代表写真もカラーのまま使ったバージョンです。各種リンクは白背景にしてメリハリをつけています。

カラー写真 + 背景白 + ホバー切替

上の「カラー写真 + 背景白」に、代表写真のホバークロスフェード(通常⇄ポップ写真)を組み合わせたバージョンです。

会社概要を写真背景に(背景白パターン)

「カラー写真 + 背景白」をベースに、会社概要セクションだけ拠点写真(_E8A9839.jpg)をボックスではなくセクション全体の背景にしたバージョンです。左側は白いグラデーションで文字を読みやすくしています。
フルページ版

sample.pdf 参考デザイン

「カラー写真 + 背景白」をベースに、sample.pdfを再現したバージョンです。並び順を USBOARDについて→代表メッセージ→各種リンク→会社概要 に変更、ヒーロー画像をグレースケールに。代表メッセージは背景をダークに戻し、写真に白いカードを重ねる見出し、引用文の横にポップ写真を並べる構成にしています。会社概要は写真フルブリード背景 + 白いカードです。
